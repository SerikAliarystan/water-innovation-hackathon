# Water Innovation Hackathon — лендинг

Innovate for Every Drop · Инновации ради каждой капли · Әр тамшы үшін — инновация

```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/
npm run deploy   # публикация на https://water-innovation-hackathon.surge.sh
```

- Настройки (призовой фонд, URL приёма заявок, контакты): `src/config.js`
- Тексты RU / ҚАЗ / EN: `src/i18n.js`
- Логотипы партнёров: `public/logos/` (сейчас заглушки — заменить на официальные SVG)
- Приём заявок в Google Таблицу + письма: `backend/README.md`
- Проверка этапов таймера: `?now=2026-11-20T10:00` (время Астаны), язык: `?lang=kk`
