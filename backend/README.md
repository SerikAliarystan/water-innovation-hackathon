# Приём заявок через Google Таблицу (бесплатно)

1. Создайте Google Таблицу → **Расширения → Apps Script**.
2. Вставьте код из `google-apps-script.gs`, укажите адреса в `ORGANIZER_EMAILS`.
3. **Развернуть → Новое развёртывание → Веб-приложение**:
   «Выполнять как: я», «Доступ: все». Разрешите доступ к Таблице и Gmail.
4. Скопируйте URL вида `https://script.google.com/macros/s/…/exec`
   в `src/config.js` → `submitEndpoint`, затем `npm run build` и выложите сайт заново.

Без `submitEndpoint` форма работает в демо-режиме: заявка сохраняется только в браузере посетителя.

Лимиты бесплатного Gmail: ~100 писем в сутки (каждая заявка = 2 письма). Для Google Workspace — 1 500 в сутки.
